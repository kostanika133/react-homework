# Taste

## Communication
- Prefers conceptual explanations and hints over complete, copy-paste code — wants to understand the "why" and write the code himself. Confidence: 0.8
- Wants short, concise instructions rather than long, detailed walkthroughs. Confidence: 0.8

## Workflow
- Prefers to be given step-by-step instructions (what to run in the terminal, what to do) and to make the changes himself, rather than having the agent edit or write files directly — even when asking for starter files, wants the content provided to paste in rather than the agent modifying files. Agent file edits should be treated as opt-in: only allowed when he explicitly grants permission. When he asks a status/verification question (e.g. "is everything done?"), he wants an answer only — explicitly tells the agent not to change anything. Confidence: 0.9
